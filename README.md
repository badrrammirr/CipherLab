# CipherLab - Cryptography Benchmarking & Security Analysis Platform

A comprehensive educational cryptography platform for implementing, analyzing, benchmarking, and comparing classical and modern cryptographic algorithms.

## Features

### Module 1: Encryption/Decryption Laboratory
- Support for 9 cryptographic algorithms
- Real-time encryption and decryption
- Key generation for modern algorithms (AES, RSA)
- Hash computation and verification for SHA-256
- Copy results to clipboard

### Module 2: Performance Benchmarking
- Measure encryption and decryption execution times
- Compare multiple algorithms simultaneously
- Configurable number of iterations for accuracy
- Visual performance comparison charts
- Statistical analysis of timing data

### Module 3: Statistical Analysis
- Character frequency distribution analysis
- Letter frequency analysis (A-Z)
- Plaintext vs ciphertext frequency comparison
- Interactive frequency charts
- Statistical information display

### Module 4: Cryptanalysis & Vulnerability Testing
- Caesar cipher brute-force attack (26 possibilities)
- Affine cipher brute-force attack (312 possibilities)
- Frequency analysis for pattern identification
- Known-plaintext attack demonstration
- Educational vulnerability explanations

### Module 5: Comparison Dashboard
- Comprehensive algorithm comparison table
- Key space comparison charts (log scale)
- Performance comparison charts
- Security analysis notes
- Quantum threat information

## Supported Algorithms

### Classical Cryptography
1. **Caesar Cipher** - Simple substitution cipher with shift
2. **Affine Cipher** - Mathematical substitution cipher (ax + b mod 26)
3. **Vigenère Cipher** - Polyalphabetic substitution using keyword
4. **Playfair Cipher** - Digraph substitution using 5x5 key matrix
5. **Rail Fence Cipher** - Transposition cipher with zigzag pattern
6. **Columnar Transposition Cipher** - Column-based transposition

### Modern Cryptography
7. **AES-256** - Advanced Encryption Standard (symmetric)
8. **RSA-2048** - Rivest-Shamir-Adleman (asymmetric)
9. **SHA-256** - Secure Hash Algorithm (cryptographic hash)
